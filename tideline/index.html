  1. 01

    Send assets from any supported chain. They land in a single account, no bridges to manage.

A preview of the SDK we plan to build. Your users would deposit from wherever their money lives, and you would receive funds on the chain you choose.

// Accept deposits from any chain
import { TideFlow } from "@tideline/sdk";

const flow = new TideFlow({
  destination: "base",
  asset: "USDC",
});

await flow.open({ user: wallet.address });
// ✓ funds arrive settled and ready
